# Freshroots Demand Planner

A rules-based demand-planning assistant for Freshroots (MESA case "Deepa's 90-Day Mandate").
It automates the SAP-export data work and Raghav's documented reorder rules. The buying decision stays human: the engine recommends, Raghav approves or overrides, and procurement places the order.

> Status: under construction. See `HANDOFF.md` for current progress and `docs/BUILD_SPEC.md` for the full spec.

## Stack
Next.js (App Router, TypeScript) · Prisma 7 + Neon Postgres · Vercel · Vitest
